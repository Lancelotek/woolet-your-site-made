# woolet-route-server (Cloudflare Worker)

Edge route server for woolet.co. Serves the 37 prerendered per-route HTML
files generated by `scripts/prerender.mjs` directly from a Worker bundle,
and passes everything else through to the Lovable origin.

Why: Lovable hosting has no directory-index resolution, so `/en/products/009`
hits the SPA fallback (`dist/index.html`) instead of the prerendered
`dist/en/products/009/index.html`. The Worker fixes that at the edge.

## Layout

```
workers/route-server/
  wrangler.toml          # routes: woolet.co/*, www.woolet.co/*
  package.json
  build-bundle.mjs       # walks dist/, emits src/prerendered.ts
  src/
    index.ts             # Worker entry
    prerendered.ts       # AUTO-GENERATED, gitignored
```

## Deploy

From repo root, first time:

```bash
cd workers/route-server
npm install
npx wrangler login         # OAuth to the CF account that owns woolet.co
npm run deploy             # runs prebuild (root vite build + prerender),
                           # build-bundle.mjs, then wrangler deploy
```

`wrangler deploy` reads `wrangler.toml` and automatically maps the routes
`woolet.co/*` and `www.woolet.co/*` to this Worker. If routes don't apply
automatically, add them in Cloudflare dashboard -> woolet.co zone ->
Workers Routes.

## Re-deploy

Whenever route metadata or prerendered HTML changes, re-run `npm run deploy`.
For CI, run the same command with `CLOUDFLARE_API_TOKEN` set (no `login`
needed).

## What it does

1. `www.woolet.co/*` -> 301 to `woolet.co/*` (Lovable origin only 302s).
2. Trailing slash normalized (except root).
3. GET/HEAD path in `PRERENDERED` map -> serve embedded HTML with
   `x-route-source: prerendered` header + 5 min edge cache.
4. Everything else -> `fetch(request)` to Lovable origin. If the response
   is HTML, HTMLRewriter strips any `og:image` / `twitter:image` tags that
   point at `lovable.app` / `id-preview-*` (Lovable preview pollution).

## Verify (after deploy)


```bash
curl -s https://woolet.co/en/products/009 | grep "<title>"
curl -s https://woolet.co/en/products/009 | grep -o '"@type":"Product"'
curl -sI https://woolet.co/en/products/009 | grep x-route-source
curl -sI https://www.woolet.co/ | grep -E "^HTTP|^location"
curl -s https://woolet.co/ | grep -c "lovable.app"   # expect 0
```
